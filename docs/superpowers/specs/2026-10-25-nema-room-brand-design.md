# Nema Room 品牌与图标设计

日期：2026-10-25。

状态：名称与造型方向已由用户选定；用户随后以“开始做”授权执行计划。生产母版与平台资源已建立，代码已接入；验证结果和剩余平台检查见实施计划。

## 意图与范围

项目当前作为开源软件，暂不考虑商业化。对外品牌名称采用 **Nema Room**，图形与现有 UI 保持一致：纸白、暖灰、墨黑、直角和清晰的结构。此次保存选定素材、维护三语言 README，并规划桌面和浏览器入口的品牌接入。

## 方案与决定

最初比较了三个方向：01 开放空间与负形 N，02 讨论线条汇成秩序，03 定制字标与 N。用户选择 01，认为它有设计感。随后探索的 A/B 版本更宽或更挺拔；用户认为过于锐利，明确返回最初 01，并说“先用这个”。因此采用原始对比稿左列 01，不采用 A/B，也不继续重设计。

## 视觉规格

- 品牌全称为 **Nema Room**。
- 采用最初对比稿左列 **01 / ROOM / N** 的开放房间／门洞轮廓、内部独立立面与负形 N。
- 保留原始 01 的比例与轮廓，不沿用更尖锐的 A/B 版本。
- 默认墨黑 `#111111`，浅色承载面 `#ffffff` 或暖灰 `#f3f2ee`。先保证纯黑白成立；朱红 `#e3241b` 不进入当前默认图标。
- 字标参考现有 Inter / Helvetica 风格；本轮没有批准新的定制字体或把生成稿文字当字体文件。
- 不增加渐变、阴影、立体材质或装饰。操作系统图标容器可遵循各平台规范，但内部标志造型保持一致。

## 后续接入约束与验收

后续可采用代码原生 SVG 母版并导出 PNG、Windows ICO、macOS ICNS。生产资源置于 `apps/desktop/assets/`，Web favicon 置于 `apps/web/app/icon.png`；完整文件映射见计划。

对外显示名称改为 Nema Room，但不得更改 appId `org.nema-project.nema-room`、数据目录、CLI 命令、包名或运行核心标识。先核查打包产物命名和启动器引用，避免外观调整影响安装升级。与其他 agent 并行时保留其修改，接入标题栏前读取最新文件。

应用接入必须覆盖安装包、窗口与任务栏、托盘、浏览器 favicon；分别检查浅色和深色背景、16/20/24/32px 小尺寸和系统缩放。macOS 托盘采用适用的 template image。不能以大图预览代替实际验证，也不能直接把 PNG 改扩展名充当平台资源。

不在本轮更改 UI 布局、业务行为、许可或发布流程，不宣称名称已完成商标清查。开源意图不改变现有 MIT 许可条款。
