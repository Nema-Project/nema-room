- Graphify is no longer bundled with the desktop app: it downloads on first use of a graph feature after a size confirmation, verified against the shipped lock, with offline component packs (`nema components pack` / `import`) for air-gapped setups, and npm and Compose host daemons on Windows, macOS, and glibc Linux can now install it the same way. An installed component that stops running can be reinstalled as a repair from Settings → Components (Reinstall) or with `nema components install graphify --force`; a repair that fails, is cancelled, or cannot download (offline mode) is reported as such, never as a successful reinstall.
