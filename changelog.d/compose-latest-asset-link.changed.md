- Public Compose installs now fetch `docker-compose.yml` from `releases/latest/download/`, the fixed-name asset each release from `v0.1.6` on carries, instead of a file on a version tag. The four READMEs, the three guides, and the three site pages give the same no-clone steps: fetch with `curl -fsSL`, check that both image pins print the same version, lock it in `.env` as `NEMA_IMAGE_TAG` (an existing value is kept and its versioned asset fetched instead), start, install the daemon at that version, and run `nema daemon`.
