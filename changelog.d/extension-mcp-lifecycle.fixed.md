- `nema daemon` now stops on Ctrl-C, SIGTERM or SIGHUP by closing first, so its stdio MCP servers (and running tasks) are stopped instead of outliving it. A second signal exits at once; a close that takes longer than 15 seconds is cut off.
- A daemon that was killed without closing no longer leaves stdio MCP servers running for good. Each running server's process is recorded in `<nema home>/run/mcp/<id>/server.json`; the next daemon stops any recorded server that is still the same process (pid and start time match) with its whole process group, before any MCP operation, and its row on the Plugins page says "stopped a copy left running by the previous daemon; start it again". Nothing is restarted on its own.
- A stdio server that exits on its own no longer leaves the rest of its process group behind.
