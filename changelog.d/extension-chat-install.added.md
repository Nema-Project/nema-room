- Ask in chat to install a skill: the Agent calls `offer_skill_install`, which pins the source like the Plugins page preview and puts a card under the reply with the skill's description, repository, commit, license, and target folder. Nothing is installed until you press Install on the card, which uses the same install service as the Plugins page and shows the same progress and cancel button. Only tasks started by your own message can offer an install. The three guides and the technical reference describe the flow.
