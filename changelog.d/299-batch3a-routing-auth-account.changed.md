- A task that fails before it reaches the model, because of account routing, a credential, or the config file, is now shown in the selected UI language: no enabled or unknown account, automatic routing off or with no account available (with the accounts set aside and why), a missing or unusable login, key, token or model, an unreadable `accounts.json` or `config.json`, a Codex login that cannot be used, and a direct-login refresh that failed or was rate limited (#299).
- The daemon sends these failures with an optional `errorCode` / `errorParams` on `task.finished`, and the hub stores the code as the failed-task notice's reason. Commands and file names in the message (`nema auth login`, `nema auth byok`, `codex login`, `accounts.json`, …) stay as written in every language. An older daemon sends no code and its failures are shown as before; messages stored before this change are not migrated (#299).
