- Chat messages can `@`-mention workspace context: a knowledge entry (`[D-12]`), a file already sent with an earlier message (`` `附件：截图 1.png` ``), or a topic (`[话题：标题]`). Mentioned entries arrive in the agent's prompt with their body (4 KiB each, 16 KiB in total; anything over that is named by id for the agent to read), a mentioned file is delivered with the task like the message's own attachments (still at most 8 files and 32 MB per task), and a topic contributes its title and a shortened anchor. A mention is the user's pointer, not a decision: it never changes an entry, and nothing is retried or converted. A message may mention at most 20 things, and each mention must be this workspace's; a mention whose text was edited out of the message is dropped on edit In the composer, typing `@` opens one menu with those three groups (entries, files you already sent, topics), writes the readable text into the message, and shows a chip above the box that removes both when clicked; an entry id typed exactly (`@D-12`) comes first.
