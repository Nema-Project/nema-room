- System messages in chat now follow the selected UI language: index ready/failed, interrupted and failed tasks, follow-up question cards, and the notes for system-started tasks (architecture diagram, diagram update, commits checked, commits without a report) carry a structured `meta.notice { code, params }`, and the web renders it from its catalog (#299).
- A failed task's message no longer has the account and model appended to its text; the page names them from the stored `meta.route`. A failure from the hub itself (older daemon without attachment or account support, missing work package) names its reason in the UI language; a daemon error is still shown as reported, inside the localised sentence, until the daemon sends error codes (#299).
- The stored fallback text of new system messages is English. The instruction text the model receives for system-started tasks is unchanged. Messages stored before this change are not migrated and render exactly as before (#299).
- The progress bar's "drawing the architecture diagram" label now follows the system message's notice code instead of matching its text; a message stored before this change, which has no notice, is still matched by its text (#299).
