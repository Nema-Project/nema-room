- The daemon can store MCP server configs (stdio or HTTP) and start, connect to, and stop them. Credentials live in private files under `~/.nema/secrets/mcp/<id>/`, or come from the daemon's environment. Config files and the extension record keep only references to them. Changing a server's command, arguments, working directory, or URL clears its stored credentials. A stdio server gets exactly its configured environment plus `PATH` and a private `HOME`, and stopping it also ends its process group. HTTP servers do not follow redirects, and a 401 or 403 shows as "needs login". On Windows, stdio servers run only under the desktop app's owned-process scope. These pieces are not yet reachable from the Plugins page or the CLI, and MCP tools are not offered to the Agent in this release.
