    あなたのパソコンだけで動く

    デスクトップ版はすべてを 1 つのアプリにまとめています。データベース、ローカルコア、Node を同梱し、Git はパソコンに入っている 2.31 以降を使います。Mac では Finder から開いたときも Homebrew と MacPorts の Git を見つけます。Docker もデータベースサーバーも不要です。議論の内容は選んだモデルプロバイダーにだけ送られ、GitHub のトークンを Nema が扱うことはありません。

    現状

    • Windows x64 デスクトップ版最新インストーラーまたは ZIP
    • macOS デスクトップ版最新、Apple シリコン
    • LinuxWeb / Compose 版
    • インストーラー署名未署名
    • 自動更新なし
    • ChatGPT サブスクリプションブラウザでログイン
    • Claude サブスクリプションClaude Code トークン
    • API キーResponses API 互換
    • コーディングエージェントCodex、Claude Code
    • ライセンスMIT

    よくある質問

    今すぐダウンロードできますか？

    できます。最新リリースには Windows x64 のインストーラー、Windows のポータブル ZIP、Apple シリコン向けのディスクイメージがあります。ZIP は展開してそのまま実行するアプリです。展開して Nema.exe を実行します。ショートカットもアンインストーラーもありません。インストーラーと ZIP はどちらも ~/.nema/desktop を使います。どちらか一方を選んでください。未署名のため、Windows では初回に「Windows によって PC が保護されました」と表示され、macOS では「プライバシーとセキュリティ」から開きます。アプリには Git 2.31 以降も必要です。Intel Mac 向けのデスクトップ版はありません。Linux では linux/amd64 の hub と web イメージを使うか、ソースからビルドします。

    費用はかかりますか？

    Nema Room 自体は MIT ライセンスのオープンソースです。項目の整理にはモデルを呼び出すため、費用や利用枠は選んだプロバイダーによります。ChatGPT や Claude のサブスクリプション、または自分の API キーを使えます。

    議論の内容はどこに送られますか？

    データベースとナレッジベースはあなたのパソコンにあります。項目を生成するときだけ、関連する内容が選んだモデルプロバイダーに送られます。サービスは既定でローカルのみで待ち受けます。インターネットに直接公開しないでください。

    エージェントはどう進捗を報告しますか？

    nema report install で Codex や Claude Code に報告フックを入れます。コミットのたびに Nema へ通知され、Nema が動いていないときは手元に保存して次回送ります。

    複数人で使えますか？

    初版は 1 人が自分のパソコンで使うものです。複数端末の同期、バックアップ、チームの閲覧専用アクセスは、ローカルコアの完成後に対応します。

    なぜ Nema？

    名は根回しに由来します。決定の前に理解を揃えつつ、食い違いも根拠も見える形で残します。

    ダウンロード

    Windows x64 と Apple シリコン向けのビルドは最新リリースにあります。Windows ではインストーラーかポータブル ZIP のどちらかを選びます。ZIP は展開して Nema.exe を実行します。ショートカットもアンインストーラーもありません。どちらも ~/.nema/desktop を使います。パソコンには Git 2.31 以降が必要です。

    ホストのコマンドは nema で、npm i -g @nema-project/nema@<locked version> から入ります。この数字は取得した docker-compose.yml の 2 つの image: が固定している版です。hub と web のイメージは linux/amd64 です。docker-compose.yml は最新 Release の固定名の資産で、両イメージをその Release の版に固定してレンダリングしたものです。取得したら 2 つの固定が同じ版か確かめ、NEMA_IMAGE_TAG=<その版> を .env に書いてから起動します（既存の値があればそれを使い、releases/download/v<locked>/docker-compose.yml を取得します）。v0.1.6 のファイルの先頭にはテンプレートの「インストール可能な版ではない」というコメントが残っていますが、固定された 2 行の image: が正しい情報です。v0.1.6 より前の固定にはリリース資産がないため、raw.githubusercontent.com/Nema-Project/nema-room/v<locked>/docker-compose.yml を取得します。Linux と macOS では先に NEMA_UID と NEMA_GID を export します。このリポジトリを開発するときは、clone してセットアップウィザードを実行します。

    # hub と web。linux/amd64 のみ。compose ファイルは最新 Release の固定名の資産です。
NEMA_FETCHED= NEMA_LOCKED= NEMA_UP= NEMA_INSTALLED=
curl -fsSL -o docker-compose.yml.download https://github.com/Nema-Project/nema-room/releases/latest/download/docker-compose.yml && mv docker-compose.yml.download docker-compose.yml && NEMA_FETCHED=1
# .env に NEMA_IMAGE_TAG があればそれを使い、代わりに .../releases/download/v<locked>/docker-compose.yml を取得します。
# hub と web の版が一致するときだけ版を表示します。何も出なければ止めます。
NEMA_VERSION=$(grep -o 'nema-room-hub:[0-9.]*' docker-compose.yml | head -1 | cut -d: -f2)
WEB_VERSION=$(grep -o 'nema-room-web:[0-9.]*' docker-compose.yml | head -1 | cut -d: -f2)
test -n "$NEMA_FETCHED" && test -n "$NEMA_VERSION" && test "$NEMA_VERSION" = "$WEB_VERSION" && echo "$NEMA_VERSION"
# .env に固定します（既存の値はそのまま）。locked が出なければ止めます。
test -n "$NEMA_FETCHED" && test -n "$NEMA_VERSION" && test "$NEMA_VERSION" = "$WEB_VERSION" && { grep -q '^NEMA_IMAGE_TAG=' .env 2>/dev/null || printf '\nNEMA_IMAGE_TAG=%s\n' "$NEMA_VERSION" >> .env; } && grep -qx "NEMA_IMAGE_TAG=$NEMA_VERSION" .env && NEMA_LOCKED=$NEMA_VERSION && echo "locked $NEMA_LOCKED"
# 以下の各行は前の行が成功したときだけ実行されます。export は Linux と macOS のみ。
export NEMA_UID="$(id -u)" NEMA_GID="$(id -g)"
test -n "$NEMA_LOCKED" && mkdir -p -m 700 "${NEMA_DATA_HOST_DIR:-$HOME/.nema/data}" && docker compose up -d && NEMA_UP=1
test -n "$NEMA_UP" && npm i -g "@nema-project/nema@$NEMA_LOCKED" && NEMA_INSTALLED=1
# .env で NEMA_HUB_PORT や NEMA_DATA_HOST_DIR を設定したら先に同じ値を export します。Compose は daemon を起動しません。
test -n "$NEMA_INSTALLED" && NEMA_DATA_DIR="${NEMA_DATA_HOST_DIR:-$HOME/.nema/data}" nema daemon --hub "http://127.0.0.1:${NEMA_HUB_PORT:-4400}"

# またはこのリポジトリをソースからビルド
git clone https://github.com/Nema-Project/nema-room.git
cd nema-room
node scripts/setup.mjs --lang ja
