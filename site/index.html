    只在你的电脑上运行

    常见问题

    现在能下载吗？

    还没有正式发布。现在可以从源码构建 Windows 桌面预览版，或者用 Docker Compose 运行 Web 版。安装包未签名，首次打开时 Windows 会提示“已保护你的电脑”。

    要花钱吗？

    Nema Room 本身以 MIT 许可开源。整理条目需要调用模型，费用或额度由你选的服务商决定：ChatGPT 或 Claude 订阅，或者你自己的 API Key。

    讨论内容会上传到哪里？

    数据库和知识库都在你的电脑上。只有生成条目时，相关内容会发给你选择的模型服务商。服务默认只监听本机，不要直接暴露到公网。

    编码 Agent 怎么回报进度？

    用 nema report install 给 Codex 或 Claude Code 装上回报钩子。提交时它会通知 Nema；Nema 没在运行时，回报先存在本地，下次再发。

    能多人一起用吗？

    首版是一个人在本机使用。多设备同步、备份和团队只读访问，会在本地核心完成之后再做。

    从源码开始试用

    需要 Node.js 22 以上和 Git。克隆仓库后运行安装向导，它会检查环境、安装依赖并带你选好模型。

    git clone https://github.com/Nema-Project/nema-room.git
cd nema-room
node scripts/setup.mjs
